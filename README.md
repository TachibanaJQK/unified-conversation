# Unified Conversation Manager — Legal Pages

Static academic project site with Terms of Service and Privacy Policy.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `unified-conversation` under `TachibanaJQK`.
2. Upload `index.html`, `terms.html`, `privacy.html`, and `style.css` into the repository root (not a nested folder).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. Once deployed, visit:
   - https://tachibanajqk.github.io/unified-conversation/
   - https://tachibanajqk.github.io/unified-conversation/terms.html
   - https://tachibanajqk.github.io/unified-conversation/privacy.html

**Before actual user-data processing:** Review legal accuracy, add a monitored contact email, and align the privacy policy with implemented storage, deletion, and AI-processing practices. Never commit API secrets.
